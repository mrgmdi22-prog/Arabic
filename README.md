# مرافئ العربية · Arabic Harbours

موقع لتعليم اللغة العربية للناطقين بغيرها، متفرّع من موقع نادي اللغة الإنجليزية.

- رحلة المرافئ: ٢١ مرفأً على خريطة بحرية، وكل مرفأ درس قراءة (`ports/`)
- قصص من كليلة ودمنة (`stories/`)
- فهم المقروء (`reading/`)
- الإملاء (`dictation/`)
- مختبر الإعراب (`irab/`)
